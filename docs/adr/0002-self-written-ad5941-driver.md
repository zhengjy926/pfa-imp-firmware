# 自写 AD5941 精简驱动，不移植 ADI 官方 SDK

项目只需单频 50kHz、2 电极、100ms 更新率的阻抗测量，且要求企业级可测性与 MISRA 合规。决定：自写 AD5941 精简驱动（SPI 传输 + 初始化 + 测量序列 + FIFO 读取），寄存器流程对照 ADI 官方 EIS 例程逐项验证。

**Considered Options**: 移植 ADI 官方 SDK（ad5940lib）——验证充分，但体量大（数十 KB）、状态机复杂、难以做寄存器级单元测试与 MISRA 合规；拒绝。

**Consequences**: 驱动按深度模块设计（窄接口、深实现），附寄存器序列单元测试（mock SPI）；未来新增测量模式（如扫频）的成本高于用官方库。
