# 回路测量工作模式内回路继电器保持闭合

进入回路测量后回路继电器闭合并保持，离开该模式（含放电准备或其他工作模式）才断开；不按测量周期开合。术中回路阻抗是放电前看一眼，500ms 窗口内对多次测量算术平均，继电器来回打会损害平稳与寿命，也不能替代放电隔离。隔离仍只靠上位机先发放电准备（ADR 0005）。

**Considered Options**: 每个测量周期开合一次，或仅在「测量窗口」脉冲闭合（旧需求）——拒绝：抖动、触点寿命，且造成假互锁。

**Consequences**: 回路测量期间 AD5941 一直挂在放电环上；上位机漏发放电准备即使能脉冲发生板时，前端持续暴露。与贴靠继电器「模式值包含闭合」对称。
