# 放电使能不属于本固件；放电前隔离由上位机命令本板执行

高压双相脉冲由脉冲发生板输出两路 PWM、经光纤驱动 IGBT 调制产生，由上位机直接使能；本板不输出 PWM、不驱动 IGBT、不使能放电，与脉冲发生板无数字互连。放电前上位机先向本板下发放电准备（停测、断回路继电器、断标测继电器、命令贴靠阻抗采集板断开），再向脉冲发生板使能放电。本固件不实现放电状态机，只处理放电准备与继电器位图；非法放电构型仍拒绝并上报。

**Considered Options**: 脉冲发生板向本板发硬件 Blank，或回路继电器闭合时禁止 IGBT（FARASTAR 同类）（拒绝：用户选定只靠上位机顺序，两板无数字互连）；本板接收放电使能/PWM（拒绝：PWM 在脉冲发生板）。

**Consequences**: 上位机漏发放电准备就使能脉冲发生板时，测量前端可能暴露于高压；该风险由上位机顺序保证，本板无法从脉冲发生板获知即将放电。
