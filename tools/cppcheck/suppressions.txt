# cppcheck 抑制清单（含 MISRA C:2012 偏离）
#
# 本文件是「已知且被接受的偏离」的唯一登记处。取证产品里，静态分析的每一条抑制
# 都要能说清为什么，因此约定：
#
#   1. 一条抑制一行，上方紧跟注释写明「为什么这条不是缺陷」；
#   2. 抑制要尽量窄——优先写成 <id>:<文件>:<行>，其次 <id>:<文件>，避免全局 <id>；
#   3. 只在个别位置成立的偏离，改用源码内 // cppcheck-suppress <id> 就近说明，
#      让理由和代码待在一起（run_cppcheck.py 已开启 --inline-suppr）；
#   4. 影响面大的偏离（例如整类 MISRA 规则）不写在这里，先补一条 ADR。
#
# 第三方与拷贝裁剪的子树本就不参与扫描（见 tools/firmware_tree.py 的
# VENDORED_SUBTREES 与 ADR 0004），不需要在这里逐条抑制。
#
# 目前没有已登记的偏离。
